01Problem

A closed-set classification model can show high training accuracy yet fail in live environments. My 2023 degree Final Year Project at UiTM Shah Alam explored face recognition attendance using VGG16 and phpMyAdmin. In live testing, closed-set classification forced nearest-neighbor decisions on unknown people and lacked transactional consistency. Rebuilding this project focuses on the transition from academic experiments to a reliable edge attendance kiosk.

02My role

Research the recognition pipeline and rebuild the application from the ground up: replacing naive CNN classification with open-set face embeddings (OpenCV YuNet + SFace ONNX), implementing transactional SQLite attendance clocking with duplicate cooldowns and audit trails, and building a zero-dependency admin portal.

03Technology

Python OpenCV YuNet SFace ONNX Cosine Metric SQLite Transactions Audit Trails Kiosk UI

04Execution

  • Preserve the original 2023 FYP research archive while modernizing the architecture for edge deployment.
  • Implement 2-stage edge vision with OpenCV YuNet for real-time face detection and SFace for 128-dimensional normalized embeddings.
  • Enforce open-set verification with cosine similarity thresholds and ambiguity margins to reject unknown faces instead of forcing an incorrect identity.
  • Implement guided 2-phase sample capture (straight, head tilts, eye movement, variable lighting) targeting 10 samples/sec up to 350 references.
  • Build explicit kiosk attendance clocking with duplicate cooldown prevention, transaction handling, and automated audit logging.
  • Develop a zero-dependency local web admin portal for attendance log review, manual fallback entries, audited corrections, and CSV export.

Architecture note: Pretrained open-source ONNX models provide edge feature extraction without fine-tuning claims. Attendance events are transactionally committed with duplicate cooldown and audit history. This prototype operates under supervised conditions; liveness verification remains a future milestone.

05Result

The rebuilt system establishes a verified local baseline: unit-tested face matching, guided enrollment, transactional SQLite event logging with idempotency, and an audited admin portal. Biometric templates remain local; no raw faces, embeddings, or attendance data are published.

06What I learned

Moving from an academic deep learning experiment to an engineered system highlighted that model accuracy is only one piece of the puzzle. Real-world edge systems require handling unknown identities safely, preventing accidental duplicate triggers, and maintaining auditable data integrity.
